# Chapter 3: MP3

## Overview

**MP3** (MPEG-1 Audio Layer III) revolutionized digital audio.

Created in 1993. Achieves ~10:1 compression with good quality.

---

## How MP3 Works

```
Audio → Filterbank → MDCT → Psychoacoustic Model → Quantization → Huffman
```

---

## Step 1: Filterbank

Split into 32 frequency subbands:

```
Full spectrum → 32 equal-width bands
Each band processed separately
```

---

## Step 2: MDCT

Transform each subband:

```
576 samples per granule
Two granules per frame
```

---

## Step 3: Psychoacoustic Model

Calculate masking thresholds:

```
1. FFT for spectral analysis
2. Find tonal and noise maskers
3. Calculate spreading function
4. Determine threshold per band
```

---

## Step 4: Quantization

Reduce precision based on thresholds:

```
Noise-to-Mask Ratio (NMR):
  If quantization noise < masking threshold: inaudible
  Allocate bits to minimize audible noise
```

### Bit Reservoir

Borrow bits between frames:

```
Complex frame: Use borrowed bits
Simple frame: Save bits for later
```

---

## Step 5: Huffman Coding

Encode quantized values:

```
32 different Huffman tables
Choose optimal table per region
```

---

## Bitrates

| Bitrate | Quality |
|---------|---------|
| 320 kbps | Transparent |
| 256 kbps | Excellent |
| 192 kbps | Very good |
| 128 kbps | Good (FM radio) |
| 96 kbps | Acceptable |
| 64 kbps | Low (voice OK) |

---

## Joint Stereo

### Intensity Stereo

High frequencies: encode direction, not separate channels.

### Mid/Side Stereo

```
M = (L + R) / 2
S = (L - R) / 2
```

More efficient for similar channels.

---

## Key Takeaways

1. MP3 = Filterbank + MDCT + Psychoacoustics + Huffman
2. ~10:1 compression at good quality
3. 128-320 kbps typical
4. Bit reservoir smooths quality
5. Still widely used despite newer formats
